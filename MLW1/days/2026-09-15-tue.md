- 1–2 problems.

### Gist
A hash table is an array plus a function from key to index. `hash(k) % capacity`
gives a slot; collisions are resolved either by **chaining** (each slot holds a
list of entries) or **open addressing** (probe to another slot). CPython's
`dict` uses open addressing with a compact layout: a sparse array of *indices*
into a dense, insertion-ordered array of entries — which is why dicts preserve
insertion order and why they got smaller in 3.6.

O(1) is *expected*, and it assumes the hash spreads keys. Worst case is O(n):
every key in one bucket. Load factor matters — CPython resizes when the table
is about two-thirds full, so a dict is never dense enough to degrade. Resizing
rehashes everything: O(n), amortized away exactly like yesterday's array
doubling.

What makes a key hashable: `__hash__` and `__eq__` that agree. `a == b` must
imply `hash(a) == hash(b)`, or lookups silently lose entries. Mutable objects
have no stable hash — that is why `list` cannot be a key and `tuple` can.

**Tonight's build:** `HashMap` with chaining — `put`, `get`, `delete`,
`__len__`, `_resize` when load factor > 0.75. Handle deletion and key-overwrite
properly; those are the two cases people get wrong.

### Gist — the one idea the series is built on
A matrix is not a grid of numbers. It is a **function**, written down by
recording where the basis vectors land. Column `j` of `A` is where `e_j` goes.
Everything else follows:

- `A @ x` is "scale each landing spot by the matching coordinate of x, then
  add" — a linear combination of the columns.
- `A @ B` is *composition*: apply B, then A. That is why it does not commute
  and why the inner dimensions must match.
- **Determinant** = the factor by which areas/volumes scale. `det == 0` means
  the transform squashes space into a lower dimension — information destroyed,
  therefore not invertible. Negative det means orientation flipped.
- **Column space** = everything reachable, i.e. the span of the columns.
  **Rank** = its dimension. **Null space** = everything crushed to zero.
- Non-square `A` of shape `(m,n)` maps n-dimensional input to m-dimensional
  output. That is all "non-square" means.

### Gauss-Jordan, the algorithm you are implementing
Build `[A | I]`. For each column: pick a pivot row (largest absolute value —
**partial pivoting**, for numerical stability), swap it up, divide that row by
the pivot, then subtract multiples of it from every other row to zero out the
column. When the left block is `I`, the right block is `A^-1`. If no non-zero
pivot exists in a column, the matrix is singular — raise, do not fudge.

Write it with triple-nested loops and lists of lists. Feel it. That is the cost
you stop paying tomorrow, and the thing you benchmark on Friday — **keep this
file**.
