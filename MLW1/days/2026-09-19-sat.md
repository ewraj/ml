## 18:00 · DSA — Contest + deep work

Standing format, every Saturday. Four parts, roughly in this shape:

### 1. Contest (~2h)
Codeforces **Div 3 or Div 4** to start; Div 2 once you are past ~1200. A
virtual contest is fine if the live timing is wrong — treat it identically,
timer on, no editorials open.

**Submit with PyPy, not CPython.** It is 5–10x faster on tight loops and it is
frequently the difference between AC and TLE on an otherwise correct solution.

Practical things that cost people rating in week 1, not skill:
- Read with `sys.stdin.buffer.read().split()` when input is large; `input()` in
  a loop is genuinely slow enough to TLE.
- Print once at the end via `"\n".join(...)`, not per line.
- Read **all** the constraints before coding. `n <= 2e5` and `n <= 2000` are
  different problems and the second one is often the easier intended solution.
- Div 3/4 A and B are usually observations, not algorithms. If you are reaching
  for a data structure on problem A, re-read the statement.

### 2. Upsolve (~1h)
**Every problem you did not get during the contest.** This is where the rating
comes from — not from the contest itself. Editorial for the *idea* only, close
it, implement from scratch. A problem you read the solution to and did not type
is a problem you did not learn.

### 3. From scratch (~45m)
One data structure a week, by hand, no library. As Block B arrives: heap, trie,
DSU, segment tree.

**Week 1:** you already built the dynamic array (Mon) and the chained hash map
(Tue). Finish whichever is still rough, then implement a **binary heap** —
`push`, `pop`, `heapify` in O(n), sift up/down — and race it against `heapq` to
see what the C implementation buys.

### 4. Log (~15m)
Update the solution log. **One line per problem: the insight, not the code.**
Also add today's misses to the re-solve queue with dates (+3, +10, +30 days) —
tomorrow's 19:00 session reads from it.

### Rating targets
1200 by month 4 · 1400 by month 8 · 1600 by month 12. Week 1 is a baseline, not
a verdict. Record the number and move on.
