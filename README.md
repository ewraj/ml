# ml

A year-long plan, in public. **Phase 1: 14 Sep - 22 Nov 2026, 60 sessions** —
foundations, numpy only, one rule: **implement before you import.**

| Week | Folder | Topic |
|---|---|---|
| W1 · 14-20 Sep 2026 | [`MLW1/`](MLW1/) | numpy from the metal · linear algebra · k-NN from scratch |

Each week folder holds the exercises and tests for that week, plus `days/` —
one markdown file per session with what to cover, the gist of the ideas, and
space to write up what actually happened.

Reference kept alongside the work: [`MLW1/git-github.md`](MLW1/git-github.md).
